# Munta Sai Karthik – Portfolio

A modern, high-performance portfolio website for Munta Sai Karthik, an **AI Systems Engineer & Full-Stack Developer**. This site is engineered for speed, responsiveness, and a premium aesthetic, replacing heavy 3D assets with lightweight, interactive code-based animations.

## Key Features

- **High-Performance Backgrounds** - Custom code-based interactive animated backgrounds replacing heavy Spline 3D scenes for optimal mobile and desktop performance.
- **Project Showcase** - Comprehensive list of 12+ AI, Blockchain, and Full-Stack projects with dynamic status badges (Live, Featured, Completed).
- **AI-Driven Branding** - Refined identity as an AI Systems Engineer with tailored experience and technical expertise sections.
- **Premium UI/UX** - Modern glassmorphism design using Outfit and Syne typography, dynamic gradients, and smooth Framer Motion transitions.
- **Fully Optimized** - Built with Vite and esbuild for lightning-fast loads and efficient production builds.

## Tech Stack

- **Frontend**: React 19 + TypeScript
- **Build Tool**: Vite (optimized with esbuild)
- **Styling**: Tailwind CSS (Glassmorphism + custom utilities)
- **Animations**: Framer Motion
- **Icons**: Lucide React
- **Deployment**: Vercel ready

## Getting Started

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```
